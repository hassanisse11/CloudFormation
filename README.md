# AWS CloudFormation Projects

A collection of Infrastructure as Code (IaC) projects completed during the Cloud Engineer Academy's AWS Fundamentals module.
These projects use AWS CloudFormation and the CLI to provision and manage infrastructure using YAML templates instead of manually creating through the console.

## What I Learned
- AWS Global Infrastructure
- Amazon VPC
- Public and Private Subnets
- Route Tables
- Internet Gateways
- Security Groups
- Amazon EC2
- Elastic Load Balancing
- Auto Scaling
- Amazon S3
- Amazon RDS
- AWS IAM
- AWS CloudFormation
- Infrastructure as Code
- AWS CLI

## Projects & Templates

### VPC & Networking
Designed and deployed a multi-AZ VPC architecture containing public and private subnets, route tables, an Internet Gateway, EC2 instances, security groups, and a Bastion Host.

### IAM
Created IAM user, group, role, and policy using CloudFormation.

### EC2 & Auto Scaling
Built EC2 based infrastructure using CloudFormation, including an Application Load Balancer, Auto Scaling Group, CloudWatch alarm, and scaling policy.

### S3
Created S3 buckets and configured static website hosting using CloudFormation.

### RDS
Created an Amazon RDS MySQL database instance using CloudFormation with automated backups.
